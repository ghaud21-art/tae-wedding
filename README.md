# 민준 ♥ 서연 모바일 청첩장

구글 시트 + 구글 드라이브로 내용을 관리하는 모바일 청첩장입니다.
글, 사진, 계좌번호 등은 전부 **구글 시트**에서 고치면 되고, 코드는 건드릴 필요가 없습니다.

- 구글 시트: https://docs.google.com/spreadsheets/d/1ubgouI2ixLTqXMW4pfe8aktwO_ti9V9UJZBmx9SU-T4/edit
- 사진 폴더(구글 드라이브): https://drive.google.com/drive/folders/1OPxzsGfkG-2rL7sUQ3xsIJNfyv1wc1xr
- 배포된 사이트: https://ghaud21-art.github.io/tae-wedding/

시트와 사진 폴더는 이미 만들어져 있고 `config.js`에도 연결이 되어 있습니다. 아래 두 가지만 하면 사이트가 켜집니다.

## 1. 시트 공유 설정 켜기 (필수, 최초 1회)

위 시트 링크를 열고 우측 상단 **[공유]** → **일반 액세스**를 **"링크가 있는 모든 사용자"** + 권한 **"뷰어"**로 바꿔주세요.
(이게 안 되어 있으면 사이트가 "정보를 불러오지 못했습니다" 화면만 보여줍니다.)

사진 폴더도 마찬가지로 **[공유]** → **"링크가 있는 모든 사용자"** + **"뷰어"**로 설정해주세요.

## 2. 참석 여부(RSVP) 저장 설정 — Apps Script (선택, 원할 때 1회)

하객이 "참석 의사 전달하기"를 누르면 시트 맨 아래에 자동으로 기록되도록 하는 설정입니다. 이 단계를 건너뛰어도 사이트는 정상 동작하고, 하객 쪽에는 참석 여부가 잘 접수된 것처럼 보이지만 실제로 시트에는 저장되지 않으니, 참석 여부를 받고 싶다면 꼭 해주세요.

1. 위 시트를 열고 상단 메뉴 **확장 프로그램 → Apps Script**를 클릭합니다.
2. 열린 편집기의 기본 코드를 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 그대로 붙여넣습니다.
3. 저장(💾) → 우측 상단 **[배포] → [새 배포]**.
4. 유형 선택 톱니바퀴 → **웹 앱** 선택.
5. "액세스 권한을 가진 사용자"를 **"모든 사용자"**로 설정 → **[배포]**.
6. 처음 배포할 때 권한 승인 화면이 나오면 본인 계정으로 승인합니다.
7. 배포 완료 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec` 형태)을 복사합니다.
8. [`config.js`](config.js)의 `RSVP_WEBAPP_URL` 값을 방금 복사한 URL로 바꾸고 저장 → GitHub에 반영 (아래 5번 참고).

## 3. 시트 편집 가이드

시트는 탭 하나에 `타입, 값1, 값2, 값3, 값4` 형식의 표 한 장으로 되어 있습니다. `타입` 열의 값으로 어느 섹션인지 구분합니다.

| 타입 | 값1 | 값2 | 값3 | 값4 |
| --- | --- | --- | --- | --- |
| 기본정보 | 키 (건드리지 마세요) | 값 | — | — |
| 인터뷰 | 순서 | 질문 | 답변 | — |
| 갤러리 | 순서 | 드라이브 파일 ID | — | — |
| 우리의시간 | 순서 | 날짜 | 제목 | 설명 |
| 안내사항 | 순서 | 영문 | 제목 | 설명 |
| 계좌번호 | 신랑측/신부측 | 예금주 | 은행 | 계좌번호 |
| 참석여부 | (자동 기록, 손대지 마세요) | | | |

- **기본정보**: `값1`(키) 열은 그대로 두고 `값2`(값) 열만 고치세요.
  - `heroImageId`, `interviewImageId`, `endingImageId`는 사진 파일 ID를 넣는 칸입니다 (아래 4번 참고).
  - `greetingText`처럼 여러 줄인 셀은 셀 안에서 `Alt+Enter`로 줄바꿈하면 사이트에도 그대로 나옵니다.
- **인터뷰 / 우리의시간 / 안내사항 / 갤러리 / 계좌번호**: 행을 통째로 복사해서 붙여넣은 뒤 내용만 바꾸면 항목이 늘어납니다. 반대로 행을 지우면 줄어듭니다. 맨 왼쪽 `타입` 열 값(예: "인터뷰")은 그대로 유지한 채 나머지 칸만 고치세요.
- **참석여부**: 손대지 마세요. Apps Script가 자동으로 맨 아래에 행을 추가합니다.

## 4. 사진 올리기 (구글 드라이브)

1. 위 사진 폴더에 메인/인터뷰/갤러리/마무리 사진을 업로드합니다.
2. 각 파일을 더블클릭해 열면 주소창에 `https://drive.google.com/file/d/`**`파일ID`**`/view` 형태의 URL이 보입니다.
3. 이 파일 ID를 복사해서 구글 시트의 해당 칸(`heroImageId`, 갤러리 행의 `값2` 등)에 붙여넣으세요.

## 5. 코드(레이아웃/디자인)를 고친 뒤 배포하기

시트 내용은 고쳐도 바로 반영되지만, `index.html` / `style.css` / `script.js` / `config.js` 같은 코드 파일을 고쳤을 때는 GitHub에 올려야 반영됩니다.

```bash
git add -A
git commit -m "수정 내용"
git push
```

몇 분 내로 https://ghaud21-art.github.io/tae-wedding/ 에 자동 반영됩니다.

## 6. 나중에 도메인 연결하기

원하는 도메인을 구매하면, 저장소 루트에 `CNAME`이라는 이름의 파일을 만들고 그 안에 도메인 주소 한 줄(예: `wedding.example.com`)만 적은 뒤, 구매처(가비아, 후이즈, Cloudflare 등)에서 해당 도메인의 DNS에 GitHub Pages용 레코드를 추가하면 됩니다. 이 단계가 필요할 때 다시 말씀해주시면 도와드리겠습니다.

## 폴더 구조

```
index.html          메인 페이지
style.css           디자인
script.js           구글 시트/드라이브 연동 + 인터랙션
config.js           시트 ID, RSVP 웹앱 URL (편집 대상)
assets/              고정 이미지 (문구 이미지 등)
apps-script/Code.gs  참석 여부 저장용 Apps Script 코드
```
