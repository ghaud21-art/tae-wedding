# 민준 ♥ 서연 모바일 청첩장

구글 시트 + 구글 드라이브로 내용을 관리하는 모바일 청첩장입니다.
글, 사진, 계좌번호 등은 전부 **구글 시트**에서 고치면 되고, 코드는 건드릴 필요가 없습니다.

---

## 1. 구글 시트 만들기 (최초 1회)

1. 이 저장소의 [`sheet-template/청첩장 데이터.xlsx`](sheet-template/청첩장%20데이터.xlsx) 파일을 내려받습니다.
2. [sheets.google.com](https://sheets.google.com) 접속 → 좌측 상단 **파일 선택 화면**에서 **[가져오기]**(또는 새 시트를 연 뒤 **파일 → 가져오기**) → **업로드** 탭에서 방금 받은 xlsx 파일을 올립니다.
3. 가져오기 위치는 **"새 스프레드시트로 삽입"** 선택 → [데이터 가져오기].
4. 시트 안에 `기본정보`, `인터뷰`, `갤러리`, `우리의시간`, `안내사항`, `계좌번호`, `참석여부` 탭 7개가 그대로 들어옵니다.
5. 내용을 원하는 대로 수정합니다 (아래 "시트별 편집 가이드" 참고).
6. 우측 상단 **[공유]** → **일반 액세스**를 **"링크가 있는 모든 사용자"** + 권한 **"뷰어"** 로 변경합니다. (이게 되어 있어야 사이트가 시트 내용을 읽어올 수 있어요.)
7. 주소창 URL에서 시트 ID를 복사합니다.
   `https://docs.google.com/spreadsheets/d/`**`이 긴 문자열`**`/edit`
8. [`config.js`](config.js) 파일을 열어 `SHEET_ID` 값을 방금 복사한 ID로 바꿉니다.

## 2. 시트별 편집 가이드

- **기본정보**: 신랑/신부 이름, 날짜, 장소, 인사말 등 키-값 형태입니다. `키` 열은 건드리지 말고 `값` 열만 수정하세요.
  - `heroImageId`, `interviewImageId`, `endingImageId`는 아래 3번 "사진 올리기"에서 얻는 파일 ID를 넣는 칸입니다.
  - `greetingText`처럼 여러 줄인 셀은 셀 안에서 `Alt+Enter`(맥은 `⌘+Enter`)로 줄바꿈하면 사이트에도 그대로 줄바꿈되어 나옵니다.
- **인터뷰 / 우리의시간 / 안내사항**: 행을 늘리거나 줄여도 됩니다. 순서 열 숫자는 참고용이며, 실제로는 시트에 있는 순서대로 표시됩니다.
- **갤러리**: `드라이브파일ID` 열에 사진의 드라이브 파일 ID를 넣습니다. 행을 추가하면 갤러리 사진도 늘어납니다.
- **계좌번호**: `구분` 열이 같은 값끼리 하나의 그룹(신랑측/신부측)으로 묶입니다.
- **참석여부**: 손대지 마세요. 하객이 참석 여부를 제출하면 자동으로 이 탭에 기록됩니다 (3번 항목 Apps Script 설정 필요).

## 3. 사진 올리기 (구글 드라이브)

1. [drive.google.com](https://drive.google.com)에 새 폴더(예: "청첩장 사진")를 만듭니다.
2. 메인/인터뷰/갤러리/마무리 사진을 이 폴더에 업로드합니다.
3. 폴더를 우클릭 → **공유** → 일반 액세스 **"링크가 있는 모든 사용자"** + **"뷰어"** 로 설정합니다. (폴더 단위로 공유하면 안의 파일도 전부 공유됩니다.)
4. 각 사진 파일을 더블클릭해 열면 주소창에 `https://drive.google.com/file/d/`**`파일ID`**`/view` 형태의 URL이 보입니다. 이 파일 ID를 복사해서 구글 시트의 해당 칸(`heroImageId`, `갤러리` 탭 등)에 붙여넣으세요.

## 4. 참석 여부(RSVP) 저장 설정 — Apps Script

하객이 "참석 의사 전달하기"를 누르면 구글 시트의 `참석여부` 탭에 자동으로 기록되도록 하는 설정입니다.

1. 방금 만든 구글 시트에서 상단 메뉴 **확장 프로그램 → Apps Script**를 클릭합니다.
2. 열린 편집기의 기본 코드를 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 그대로 붙여넣습니다.
3. 저장(💾) → 우측 상단 **[배포] → [새 배포]**.
4. 유형 선택 톱니바퀴 → **웹 앱** 선택.
5. "액세스 권한을 가진 사용자"를 **"모든 사용자"**로 설정 → **[배포]**.
6. 처음 배포할 때 권한 승인 화면이 나오면 본인 계정으로 승인합니다.
7. 배포 완료 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec` 형태)을 복사합니다.
8. [`config.js`](config.js)의 `RSVP_WEBAPP_URL` 값을 방금 복사한 URL로 바꿉니다.

시트 내용을 나중에 또 고쳐도 이 배포는 그대로 유지되니, 이 설정은 처음 한 번만 하면 됩니다.

## 5. 로컬에서 미리보기

구글 시트/드라이브 공유 설정만 되어 있으면 `index.html`을 더블클릭해서 브라우저로 바로 열어도 정상 동작합니다. 별도 서버가 필요 없습니다.

## 6. GitHub Pages로 배포

이미 이 저장소가 GitHub의 `tae-wedding` 저장소로 연결되어 있습니다. 파일을 고친 뒤에는:

```bash
git add -A
git commit -m "청첩장 내용 수정"
git push
```

GitHub Pages 설정이 켜져 있으면 몇 분 내로 아래 주소에 자동 반영됩니다.

## 7. 나중에 도메인 연결하기

원하는 도메인을 구매하면, 저장소 루트에 `CNAME`이라는 이름의 파일을 만들고 그 안에 도메인 주소 한 줄(예: `wedding.example.com`)만 적은 뒤, 구매처(가비아, 후이즈, Cloudflare 등)에서 해당 도메인의 DNS에 GitHub Pages용 레코드를 추가하면 됩니다. 이 단계가 필요할 때 다시 말씀해주시면 도와드리겠습니다.

## 폴더 구조

```
index.html          메인 페이지
style.css           디자인
script.js           구글 시트/드라이브 연동 + 인터랙션
config.js           시트 ID, RSVP 웹앱 URL (편집 대상)
assets/              고정 이미지 (문구 이미지 등)
sheet-template/      구글 시트로 가져올 원본 xlsx
apps-script/Code.gs  참석 여부 저장용 Apps Script 코드
```
